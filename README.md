## 🎯 Objetivos Pedagógicos

1. **Prática Realista (*Hands-On*):** Aprender programação, redes, infraestrutura e cibersegurança resolvendo problemas reais de mercado.
2. **Boas Práticas de Engenharia:** Uso de controle de versão com Git/GitHub, documentação em Markdown (`README.md`) e organização de arquitetura limpa.
3. **Mentalidade de Segurança (*Security by Design*):** Compreender vulnerabilidades em laboratório controlado para projetar sistemas resilientes.
